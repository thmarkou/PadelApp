# PadelApp — Product brief (club OS)

Κάθε νέο chat στο `PadelApp` διαβάζει αυτό το αρχείο **και** το [PLAN.md](PLAN.md) πριν γράψει κώδικα.

Τελευταία αλλαγή κατεύθυνσης: **αυτόνομο club**, σαν Padelmatch **χωρίς εθνικό tour**. Τρία περιβάλλοντα, **ένα API** στο club.

## Τι είναι

Λειτουργικό σύστημα για ένα padel club (Ελλάδα πρώτα). Όχι marketplace. Όχι εθνικό πρωτάθλημα / κοινό ranking πολλών club.

Πουλάμε: κρατήσεις + επίπεδα που τα ορίζει το club + τουρνουά **του club** + ζευγάρια.

```text
Laptop γραμματείας  →  desk (browser)     ─┐
iPad / τάμπλετ      →  ίδια εφαρμογή Expo ─┼─  API + βάση στο VPS του club
Κινητό παίκτη       →  ίδια εφαρμογή Expo ─┘
```

Ένα binary στο App Store και στο Google Play (`com.padelapp.app`) για iPhone, iPad και Android. Η ρεσεψιόν στο laptop ανοίγει το **desk site** του ίδιου club, όχι δεύτερη βάση.

Κάθε club είναι **δική του εγκατάσταση**. Τα δεδομένα μένουν στο ΑΦΜ του πελάτη.

## Τι δεν είναι (κλείδωμα)

- Δεν φυλάμε εμείς τα τηλέφωνα όλων των club σε έναν δικό μας server ως κανονικό προϊόν.
- Δεν φτιάχνουμε ξεχωριστό app ανά club στο Store.
- Δεν υπάρχει **εθνικό πρωτάθλημα**, κοινό ranking Ελλάδας, Finals, ή δίκτυο τύπου Padelmatch Tour / Playtomic.
- Δεν είναι εφαρμογή Windows ως κύριο προϊόν.

## Τρία περιβάλλοντα

| Περιβάλλον | Ποιος | Τι είναι |
|---|---|---|
| **Web desk** | owner, reception, (coach) | Browser στο laptop του γραφείου. Κύριο εργαλείο γκισέ. |
| **iPad / τάμπλετ** | ρεσεψιόν ή προπονητής στο γήπεδο | Ίδια Expo εφαρμογή, διάταξη για μεγάλη οθόνη. |
| **Κινητό** | παίκτης (και staff εκτός γραφείου) | Ίδια Expo εφαρμογή. |

Ο παίκτης **δεν** μπαίνει στο desk. Αν ανοίξει το URL με λογαριασμό player, βλέπει άρνηση.
Πρώτη είσοδος στο κινητό: ο παίκτης κάνει **εγγραφή** (όχι μόνο σύνδεση). Staff λογαριασμοί τους ανοίγει το club.

## Πρώτος πελάτης

Ιδιοκτήτες που θέλουν **αυτόνομο** σύστημα (όχι δέσμευση Padelmatch). Η ίδια γραμμή στήνεται και σε άλλα club (κλίμακα ~10 στην Ελλάδα).

## Γλώσσες

- v1: **Ελληνικά και Αγγλικά**, επίσημα, από την πρώτη οθόνη (app και desk).
- Η γλώσσα ακολουθεί τη συσκευή / τον browser, με χειροκίνητη αλλαγή.
- Κάθε κείμενο οθόνης περνάει από αρχεία μετάφρασης.

## MVP — τι κάνει το club

1. Δυναμικά γήπεδα (indoor/outdoor, ωράριο, συντήρηση).
2. Ημερολόγιο / σλοτ + λίστα αναμονής + ακύρωση με κανόνα του club.
3. Παίκτες: προφίλ, επικοινωνία, φύλο, έτος γέννησης, επίπεδο δυναμικότητας.
4. Επίπεδα: A/B/C + κλίμακα 1.0–7.0. Επιβεβαίωση από staff. Elo από αποτελέσματα (club, όχι εθνικό).
5. Open match «λείπει 1 / 2» με φίλτρο ± επίπεδο.
6. Ζευγάρια ίσης δύναμης (snake / Mexicano). Καθημερινό σλοτ: μόνο δύναμη, όχι φύλο.
7. Τουρνουά **του club**: κατηγορίες (άνδρες / γυναίκες / μικτό = άντρας+γυναίκα vs άντρας+γυναίκα), presets, σκορ, standings.
8. Ολοκληρωτική διαγραφή παίκτη (GDPR). Ο owner δεν διαγράφεται από αυτό το path.
9. **Web desk + iOS/iPad/Android** πάνω στο ίδιο API.

## Ρόλοι

| Ρόλος | Desk / iPad | Κινητό |
|---|---|---|
| Owner / reception | Ημερολόγιο, κρατήσεις, παίκτες, γήπεδα, ρυθμίσεις, τουρνουά (εγγραφές / γύροι / σκορ) | Κράτηση και εγγραφή παίκτη. Staff στο κινητό μόνο αν λείπουν από το γραφείο |
| Coach | Ημερολόγιο, επίπεδα, σκορ, ζευγάρια | Στο γήπεδο |
| Player | Όχι | Σλοτ, open match, προφίλ, τουρνουά του club |

## Τουρνουά — δομή (αμετάβλητη)

Americano, Mexicano, King of the Court, knockout, όμιλοι+KO, box league, round robin — **μέσα στο club**.

Δημιουργία: format, scoring, μία ή περισσότερες κατηγορίες.

| Κανόνας | Ποιος εγγράφεται | Ζευγάρι |
|---|---|---|
| Ανδρών | άντρες | 2 άντρες |
| Γυναικών | γυναίκες | 2 γυναίκες |
| Μικτό | άντρες και γυναίκες | **άντρας+γυναίκα vs άντρας+γυναίκα** |

Προαιρετικά: όριο ηλικίας και ζώνη επιπέδου του club.

Χωρίς φύλο ή έτος γέννησης → μήνυμα, όχι σιωπηλή απόρριψη. Ηλικία από **έτος γέννησης**.

## Τουρνουά — μέτρηση

**Επίσημο (FIP):** Advantage / Golden Point / Star Point · set στους 6+TB ή mini-set · ματς 1 set / Bo3 / Bo3+super TB.

**Κοινωνικό:** φιξ πόντοι 16/21/24/32 · χρόνος 8–15′ · KOTC race to 4/5/7.

Presets club όπως πριν. Δεν υπάρχει βαθμολογία εκτός club.

## Ζευγάρια ίσης δύναμης

Κοντινό ατομικό rating και κοντινό άθροισμα ζευγαριού. Snake ή Mexicano. Admin override πριν τη σέντρα.

## Παραμετρικότητα

Νέο club = νέες ρυθμίσεις, όχι νέο app και όχι νέο desk binary. Κανόνας: χωρίς `if (clubName === ...)`.

## Πού κάθονται τα δεδομένα

- API + Postgres στο VPS του club (`https://api.το-club.gr`).
- Desk στο ίδιο μηχάνημα (`https://desk.το-club.gr`).
- Η εφαρμογή δείχνει στο API εκείνου του club.
- Εμείς στήνουμε και κάνουμε support. Δεν μαζεύουμε όλα τα club σε μία δικιά μας βάση.

Χωρίς server του club, συσκευές και laptop δεν μοιράζονται αλήθεια.

## Αρχιτεκτονική (κλείδωμα)

- TypeScript, χωρίς `any` χωρίς τεκμηρίωση
- Mobile + iPad: Expo / React Native, iOS **και** Android, bundle `com.padelapp.app`
- Desk: `apps/web` (Next.js), μόνο staff, ίδιο API
- i18n: ξεχωριστά αρχεία γλώσσας σε mobile και web, κλειδιά σταθερά
- `packages/shared`: τύποι, Club Settings, μηχανές σλοτ / ζευγαριών / Elo
- `apps/api`: JSON API της εγκατάστασης — το μιλούν app και desk
- Node 20, φάκελος απομονωμένος, Metro **8084**, desk dev **3041**
- Δοκιμή iOS σε πραγματικό iPhone (14 Pro Max) μέσω Xcode. iPad: ίδια εφαρμογή, μεγάλη οθόνη. Desk: browser.
