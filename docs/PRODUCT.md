# PadelApp — Product brief (club OS)

Κάθε νέο chat στο `PadelApp` διαβάζει αυτό το αρχείο **και** το [PLAN.md](PLAN.md) πριν γράψει κώδικα.

Τελευταία αλλαγή κατεύθυνσης: **hosted SaaS**, υποδομή σαν Padelmatch / Book+Play. Εμείς τρέχουμε τα πάντα σε data center **στην Ευρωπαϊκή Ένωση**. Το club μπαίνει μόνο στο web backoffice. Ο παίκτης μόνο στην εφαρμογή.

## Τι είναι

Λειτουργικό σύστημα για padel club (Ελλάδα πρώτα). Όχι marketplace μεταξύ αγνώστων. Όχι εθνικό πρωτάθλημα / κοινό ranking πολλών club.

Πουλάμε: κρατήσεις + επίπεδα που τα ορίζει το club + τουρνουά **του club** + ζευγάρια. Η εμφάνιση είναι δική μας — **όχι** κλώνος UI του Padelmatch.

```text
Γραμματεία (browser)     →  desk  ─┐
Κινητό παίκτη (Expo)     →  app   ─┼─  δικό μας API + Postgres στην ΕΕ
Staff στο γήπεδο (ίδιο app, προαιρετικά) ─┘         αντίγραφα + 24/7
```

Ένα binary στο App Store και στο Google Play (`com.padelapp.app`). Ένα desk URL για όλα τα club. Ο πελάτης **δεν** αγοράζει server, **δεν** στήνει βάση, **δεν** ανοίγει Hetzner.

Νέο club = νέος λογαριασμός στην πλατφόρμα μας (`club_id`), όχι νέα εγκατάσταση μηχανήματος.

## Τι δεν είναι (κλείδωμα)

- Δεν δίνουμε στον πελάτη VPS «στο ΑΦΜ του» ως κανονικό προϊόν.
- Δεν φτιάχνουμε ξεχωριστό app ανά club στο Store.
- Δεν υπάρχει **εθνικό πρωτάθλημα**, κοινό ranking Ελλάδας, Finals, ή δίκτυο τύπου Padelmatch Tour / Playtomic.
- Δεν αντιγράφουμε την οθόνη του Padelmatch — μόνο το μοντέλο φιλοξενίας (εμείς τα μηχανήματα, αυτοί το κλειδί).
- Δεν είναι εφαρμογή Windows ως κύριο προϊόν.

## Δύο επιφάνειες για τον πελάτη

| Επιφάνεια | Ποιος | Τι είναι |
|---|---|---|
| **Web backoffice** | owner, reception, (coach) | Browser. Μοναδικό εργαλείο διαχείρισης της επιχείρησης: ημερολόγιο, κρατήσεις, παίκτες, γήπεδα, τουρνουά, ρυθμίσεις. |
| **Mobile app** | παίκτης (δυνητικός ή μέλος) | Expo, iPhone / Android. Κλείσιμο γηπέδου, open match, προφίλ, τουρνουά. Εγγραφή μόνος του. |

Το ίδιο Expo binary μπορεί να το ανοίξει staff στο γήπεδο (iPhone / iPad) με staff λογαριασμό. Δεν είναι δεύτερο προϊόν και δεν αντικαθιστά το desk.

Ο παίκτης **δεν** μπαίνει στο desk. Αν ανοίξει το URL με λογαριασμό player, βλέπει άρνηση.
Πρώτη είσοδος στο κινητό: ο παίκτης κάνει **εγγραφή**. Staff λογαριασμούς τους ανοίγει το club από το desk.

## Πρώτος πελάτης

Ιδιοκτήτες που θέλουν **αυτόνομο** σύστημα χωρίς εθνικό tour. Ανοίγουν λογαριασμό, μπαίνουν στο desk, οι παίκτες κατεβάζουν το app. Κλίμακα ~10 club στην Ελλάδα πάνω στην **ίδια** πλατφόρμα.

## Γλώσσες

- v1: **Ελληνικά και Αγγλικά**, επίσημα, από την πρώτη οθόνη (app και desk).
- Η γλώσσα ακολουθεί τη συσκευή / τον browser, με χειροκίνητη αλλαγή.
- Κάθε κείμενο οθόνης περνάει από αρχεία μετάφρασης.

## MVP — τι κάνει το club

1. Δυναμικά γήπεδα (indoor/outdoor, ωράριο, συντήρηση).
2. Ημερολόγιο / σλοτ + λίστα αναμονής + ακύρωση με κανόνα του club.
3. Παίκτες: προφίλ, επικοινωνία, φύλο, έτος γέννησης, επίπεδο δυναμικότητας.
4. Επίπεδα: A/B/C + κλίμακα 1.0–7.0. Επιβεβαίωση από staff. Elo από αποτελέσματα (club, όχι εθνικό).
5. Open match «λείπει 1 / 2» με φίλτρο ± επίπεδο.
6. Ζευγάρια ίσης δύναμης (snake / Mexicano). Καθημερινό σλοτ: μόνο δύναμη, όχι φύλο.
7. Τουρνουά **του club**: κατηγορίες (άνδρες / γυναίκες / μικτό = άντρας+γυναίκα vs άντρας+γυναίκα), presets, σκορ, standings.
8. Ολοκληρωτική διαγραφή παίκτη (GDPR). Ο owner δεν διαγράφεται από αυτό το path.
9. **Web desk + iOS/Android** πάνω στο **ίδιο** hosted API.

## Ρόλοι

| Ρόλος | Web desk | Κινητό |
|---|---|---|
| Owner / reception | Ημερολόγιο, κρατήσεις, παίκτες, γήπεδα, ρυθμίσεις, τουρνουά | Ίδια credentials αν χρειαστεί στο γήπεδο |
| Coach | Ημερολόγιο, επίπεδα, σκορ, ζευγάρια | Στο γήπεδο: σκορ / ζευγάρια. Όχι δημιουργία τουρνουά, όχι ρυθμίσεις |
| Player | Όχι | Κλείσιμο γηπέδου, open match, προφίλ. Βλέπει τουρνουά και σκορ. Δεν δημιουργεί τουρνουά ούτε αλλάζει το club |

## Τουρνουά — δομή (αμετάβλητη)

**v1 μέσα στο club:** Americano, Mexicano, King of the Court, knockout, όμιλοι+KO.

Round robin και box league — μετά το πρώτο live club, όχι τώρα.

Δημιουργία: format, scoring, μία ή περισσότερες κατηγορίες, **ημέρες αγώνα**. Κάθε ημέρα παίρνει τα ίδια χρονικά παράθυρα με την Padelmatch: καθημερινή 17:00–19:15 / 19:15–21:30 / 21:30–23:45, Σαββατοκύριακο από 09:00 ως 00:00. `startsOn` είναι η πρώτη ημέρα.

Στην εγγραφή ο παίκτης είτε επιβεβαιώνει ότι είναι διαθέσιμος **όλες τις ώρες**, είτε διαλέγει μέχρι **8 ώρες που μπορεί**. Χωρίς ημέρες αγώνα (παλιά τουρνουά) η εγγραφή μένει «όλες οι ώρες».

| Κανόνας | Ποιος εγγράφεται | Ζευγάρι |
|---|---|---|
| Ανδρών | άντρες | 2 άντρες |
| Γυναικών | γυναίκες | 2 γυναίκες |
| Μικτό | άντρες και γυναίκες | **άντρας+γυναίκα vs άντρας+γυναίκα** |

Προαιρετικά: όριο ηλικίας και ζώνη επιπέδου του club.

Χωρίς φύλο ή έτος γέννησης → μήνυμα, όχι σιωπηλή απόρριψη. Ηλικία από **έτος γέννησης**.

## Τουρνουά — μέτρηση

**Επίσημο (FIP):** Advantage / Golden Point / Star Point · set στους 6+TB ή mini-set · ματς 1 set / Bo3 / Bo3+super TB.

**Κοινωνικό:** φιξ πόντοι 16/21/24/32 · χρόνος 8–15′ · KOTC race to 4/5/7.

Presets club όπως πριν. Δεν υπάρχει βαθμολογία εκτός club.

## Ζευγάρια ίσης δύναμης

Κοντινό ατομικό rating και κοντινό άθροισμα ζευγαριού. Snake ή Mexicano. Admin override πριν τη σέντρα.

## Παραμετρικότητα

Νέο club = νέες ρυθμίσεις στην ίδια πλατφόρμα, όχι νέο app και όχι νέο desk binary. Κανόνας: χωρίς `if (clubName === ...)`. Κάθε γραμμή στη βάση έχει `club_id`. Club A δεν διαβάζει Club B.

## Πού κάθονται τα δεδομένα

- **Εμείς** φιλοξενούμε API, desk και PostgreSQL σε data center **μέσα στην ΕΕ**.
- Καθημερινό αντίγραφο βάσης + κράτημα αρκετών ημερών. Στόχος: η υπηρεσία να είναι πάνω **24/7**.
- Το club δεν αγοράζει μηχάνημα. Μπαίνει στο desk URL. Το app δείχνει στο δικό μας API.
- Είμαστε εκτελών την επεξεργασία (GDPR) για λογαριασμό κάθε club. Λεπτομέρειες: [HOSTING.md](HOSTING.md), [PRIVACY.md](PRIVACY.md).

Χωρίς τη δική μας πλατφόρμα, desk και κινητό δεν μοιράζονται ημερολόγιο.

## Αρχιτεκτονική (κλείδωμα)

- TypeScript, χωρίς `any` χωρίς τεκμηρίωση
- Mobile: Expo / React Native, iOS **και** Android, bundle `com.padelapp.app`
- Desk: `apps/web` (Next.js), μόνο staff, ίδιο API
- i18n: ξεχωριστά αρχεία γλώσσας σε mobile και web, κλειδιά σταθερά
- `packages/shared`: τύποι, Club Settings, μηχανές σλοτ / ζευγαριών / Elo
- `apps/api`: **ένα** JSON API για όλα τα club — το μιλούν app και desk
- Node 20, φάκελος απομονωμένος, Metro **8084**, desk dev **3041**
- Παραγωγή: PostgreSQL 16 στην ΕΕ, όχι PGlite
- Δοκιμή iOS σε πραγματικό iPhone (14 Pro Max) μέσω Xcode. Desk: browser.
