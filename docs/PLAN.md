# PadelApp — πλάνο υλοποίησης

Πηγή προϊόντος: [PRODUCT.md](PRODUCT.md).

Δύο επιφάνειες στον πελάτη, **ένα hosted API** στην ΕΕ. **Όχι** εθνικό πρωτάθλημα. **Όχι** VPS στον πελάτη.

```text
Desk (browser, backoffice)  ─┐
Κινητό παίκτη (Expo)        ─┼─  JSON  →  δικό μας API  →  Postgres ΕΕ + αντίγραφα
Staff στο γήπεδο (ίδιο app) ─┘
```

## Αρχές

1. Παίκτης στο κινητό. Γραμματεία στο **web desk**. Ίδιοι κανόνες, ίδιο API.
2. Ελληνικά και Αγγλικά από την ημέρα 1 σε app και desk.
3. Παραμετρικό club: ρυθμίσεις, όχι hardcoded. Πολλά club στην ίδια βάση (`club_id`).
4. Δεδομένα σε **δικό μας** data center στην ΕΕ. Εμείς 24/7 και backups.
5. Isolated repo: `nvm use`, Metro **8084**, desk **3041**, `.env.padelapp`.
6. Δεν φτιάχνουμε εθνικό ranking / tour. Δεν κλωνάρουμε UI Padelmatch.

## Φάση 8 — desk + iPad + ενημέρωση υπάρχοντος

Σειρά. Κάθε βήμα πάνω στο ίδιο API.

### 8.1 Κλείδωμα και θεμέλιο desk — έγινε

- PRODUCT / PLAN / README: web desk επιτρέπεται, εθνικό tour απαγορεύεται. Φιλοξενία: [HOSTING.md](HOSTING.md).
- CORS: προαιρετικό `PADELAPP_WEB_ORIGIN`.
- Desk: login staff-only, κέλυφος πλοήγησης, i18n el+en, `npm run lint:i18n` και για web.

### 8.2 Desk ημερολόγιο (update του παλιού `/calendar`) — έγινε

- Ημέρα, διάρκεια, γήπεδα, κράτηση, ακύρωση — ίδιο API με το κινητό.
- Staff shell (όχι μόνες σελίδες χωρίς nav).

### 8.3 Desk παίκτες, γήπεδα, τουρνουά, ρυθμίσεις — έγινε

- Λίστες: `/players`, `/courts`, `/tournaments`, `/settings`.
- Φόρμες: νέος/επεξεργασία παίκτη (+ επιβεβαίωση επιπέδου), νέο/επεξεργασία γηπέδου, νέο τουρνουά club.
- Λεπτομέρεια τουρνουά στο desk: εγγραφές, γύρος, σκορ (Elo). Το κινητό μένει για τον παίκτη.
- Παίκτης δεν βλέπει desk.

### 8.4 Κινητό παίκτη — έκλεισε

Ο παίκτης κλείνει γήπεδο και βλέπει τουρνουά / σκορ. Δεν φτιάχνει τουρνουά, δεν αγγίζει ρυθμίσεις ή λίστες παικτών. Owner / ρεσεψιόν στο κινητό = ίδια δουλειά με το desk.

### 8.4a iPad (ίδια εφαρμογή, διάταξη) — έγινε (στήλες ημερολογίου)

- Ημερολόγιο σε στήλες όταν η οθόνη είναι μεγάλη (`>= 768`).
- Δεν φτιάχνουμε δεύτερο native app.

### 8.4b Εγγραφή παίκτη (πρώτη είσοδος) — έγινε

- `POST /auth/register`: ρόλος `player` μόνο, session όπως το login.
- Αν η ρεσεψιόν έχει ήδη καρτέλα με το ίδιο email (χωρίς λογαριασμό), δένεται εκεί.
- Οθόνη εγγραφής στο κινητό. Staff δεν αυτο-εγγράφεται.

### 8.5 Κενά «σαν Padelmatch» χωρίς tour — έκλεισε

- Elo, Americano, knockout, όμιλοι+KO, King of the Court — έγιναν.
- Round robin / box league, εγγραφή ως ζευγάρι, όριο εγγραφών, wallet, μαθήματα, Excel — **όχι σε αυτό το delivery**. Μετά το πρώτο live club, αν το ζητήσει.

### 8.6 Hosted πλατφόρμα ΕΕ — μόνο αυτό μένει

Τελευταίο task του v1. Λεπτομέρειες: [HOSTING.md](HOSTING.md).

- Ένα API + ένα desk + μία Postgres σε data center **εντός ΕΕ**.
- Το κινητό production δείχνει σταθερά στο δικό μας API. Ο παίκτης βάζει κωδικό club.
- Νέο club = γραμμή στη βάση, όχι νέο μηχάνημα.
- Καθημερινό αντίγραφο + health 24/7.
- Το isolation test (A δεν βλέπει B) μένει υποχρεωτικό.

### Αργότερα (μετά το πρώτο live club, αν το ζητήσει)

- Wallet / credits
- Μαθήματα / ακαδημίες
- Excel reports
- Round robin
- Box league

## Καθημερινό dev

```bash
nvm use
npm run dev:api      # :3040
npm run dev:web      # desk :3041
npm run dev:mobile   # Metro 8084
```

Seed: `owner@club-a.local` / `padel-dev` (μόνο εσωτερικά).

Νέο κείμενο οθόνης = κλειδί σε `el` και `en` (mobile και/ή web). Αλλιώς το lint αποτυγχάνει.
